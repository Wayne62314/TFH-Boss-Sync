# TFH Boss Sync

TFH 非官方 Windows 实验性社区 MOD，仅支持奥莉与 VV。默认英文界面，点击“中文”切换；语言不影响战斗规则。

## 双方必须开启相同版本

先和对手约定：双方下载同一个 Release，在主菜单连接工具，并在整场对局保持运行。每一端都会对 P1/P2、自己/对方的角色应用相同规则。

单边开启或版本不同可能造成“平行时空”：双方看到不同动作、血量乃至各自获胜。**这属于不同步，不是可靠的安装检测或自动拒绝对战机制。** 当前没有 MOD 握手、版本协商、远端开启检测或专用匹配隔离。本机“已连接”不代表对面已开启。不要对不知情玩家或未同意的比赛使用；出现异常立即停赛，双方重启游戏。

## 下载与启动

1. 在 GitHub Releases → Assets 下载 `TFH-Boss-Sync-v0.5.0-windows-x64.zip`，不是自动生成的 Source code。
2. 完整解压到独立、可写的目录，如 `D:\TFH-Boss-Sync` 或桌面文件夹。**不放入游戏目录，不直接在压缩包内运行。** 保留 EXE 旁整个 `_internal` 文件夹。
3. 已含运行环境，不需要安装 Python，不需要 Setup.cmd，不需要替换游戏文件。程序未签名；不要关闭安全软件或绕过安全策略。
4. 关闭旧 MOD 工具；之前连接过工具时，先完整重启游戏。正常通过 Steam/Epic 启动 TFH，停在主菜单。
5. 打开 `TFH-Boss-Sync.exe`，刷新并选择本机游戏，确认已和对手约定相同版本，点击连接。每位玩家通常只连自己电脑上的一个游戏；本机双端测试可 Ctrl 多选两个。
6. 双方均显示“已连接”后再开新对局，正常选择奥莉或 VV。选角立绘不替换。两个角色规则固定同时启用，不提供导致两端强度不一致的单边开关。
7. 结束时双方先回主菜单，点击停止；继续玩原版或重新连接前，重启已连接的游戏。停止工具不会安全撤销对局中的强化标记。界面对连接尝试后的旧进程采用保守重启要求。

覆盖已调查的本地训练、双人、人机及网络对战模式分支；菜单和未知模式不修改。不承诺剧情/场景兼容。不含自动防御、拆投、大熊、三阶段奥莉、Fred 热键包或额外键盘快捷键。

## Steam / Epic

作者已在同一台电脑的 Steam 和 Epic 两个实例中测试核心玩法，0.4.4 的空中入口修复获实测确认。0.5.0 在此基础上加入 UI 和单实例连接；这不等于新增的跨电脑或高延迟回滚验证。

只接受已经核对的两种 EXE 与资源哈希，详见英文 README 的完整列表。游戏更新、其他商店构建、修改过的角色资源、松散覆盖或其他工具可能被拒绝；不要绕过校验。界面商店标签只是按路径推测，真实兼容性以 EXE 哈希校验为准。不解锁 DLC，不改认证或网络协议，不改游戏文件与存档。

## 故障与隐私

退出日志澄清：作者已确认，旧测试末尾出现 `Invalid Oleander resources` 时是主动关闭两个游戏。因此这次属于退出期间观察到的保护性停止，不作为已确认的对局玩法故障；内部具体触发原因尚未追踪。如果正常游玩中出现该提示，请停止、重启并单独反馈。跨电脑与回滚验证仍不完整，所以仍标为实验版。

- 找不到游戏：先启动，再刷新；工具需要有权访问目标进程，权限级别应匹配。不要关闭安全控制。
- 版本/签名/菜单错误：重启受影响游戏，关闭冲突工具，确认支持的构建；不要局中连接。
- 没有强化：等“已连接”后重新开一局，选普通奥莉/VV；按招式说明使用游戏按键，不是键盘字母。
- 不同步：停止、核对版本和资源、双方重启；本工具没有自动恢复或远端 MOD 检测。
- 日志在 EXE 旁 `logs/`，可能含本地路径与进程信息；分享前检查脱敏，不会自动上传。

招式见 `MOVES.zh-CN.md`。源码架构、构建方法、精确哈希与测试命令见英文 `README.md`；第三方运行库许可证在便携包 `licenses/`。不附带游戏 EXE、资源或提取脚本。
